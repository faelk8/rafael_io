EXPERIÊNCIA PROFISSIONAL

Arquitetura medalhão com Dremio e S3

Integração de dados de MongoDB e PostgreSQL em uma arquitetura medalhão na AWS, com cargas automatizadas três vezes ao dia e dados preparados para acelerar as análises de BI.

Dremio Amazon EC2 Amazon S3 MongoDB PostgreSQL Arquitetura medalhão

Problema e objetivo

Os dashboards dependiam da execução de consultas diretamente nos bancos de origem, o que aumentava o tempo de carregamento dos dados e concorrendo pelo recurso. Além disso, as análises precisavam combinar informações de diferentes fontes. O objetivo foi estruturar uma base analítica com dados previamente tratados e integrados, reduzindo a dependência dessas consultas durante o consumo pelo BI.

Uma grande vangatem em utilizar essa solução que era tudo feito em sql e não precisa de código em python, java ou outra linguagem de programação, o que facilita a manutenção e evolução da solução.

Arquitetura da solução

A solução utilizava o Amazon EC2 para executar as rotinas de coleta e processamento de dados de MongoDB e PostgreSQL. Os dados eram organizados nas camadas da arquitetura medalhão e persistidos no Amazon S3 após o processamento de cada etapa. O Dremio apoiava o tratamento e a preparação das consultas para disponibilizar os dados ao BI.

Funcionamento

As cargas eram executadas automaticamente três vezes ao dia. A cada execução, os dados eram coletados nas fontes, tratados ao longo das camadas e armazenados no S3 para consumo analítico. Esse fluxo antecipava o trabalho de preparação dos dados, permitindo que o BI acessasse informações já processadas, em vez de repetir esse trabalho a cada consulta aos bancos de origem.

Minha participação

Atuei de ponta a ponta na sustentação e evolução da solução, com autonomia para administrar a infraestrutura na AWS, desenvolver e manter as consultas e planejar as cargas. Também fui responsável por adequar os dados às necessidades do BI, conectando as demandas de análise ao trabalho técnico de coleta, transformação e disponibilização das informações.

Manutenção e automação

A operação combinava cargas automatizadas com a manutenção das consultas e dos tratamentos de dados. Minha responsabilidade incluía manter a infraestrutura que sustentava essas rotinas e ajustar a preparação dos dados conforme as necessidades de consumo. O planejamento das cargas considerava a frequência de atualização do BI e a disponibilização dos dados processados no S3.

Quando tinha a necessidade de alterar a frequência das cargas, eu ajustava o agendamento das rotinas e até mesmo criar novas tabelas de consumo no Dremio para atender a novas demandas de análise se torna muito simples e eficiente, pois é facil de testar e colocar em produção.

Resultados

O carregamento dos dados para os dashboards ficou mais rápido em comparação com a execução de consultas diretamente nos bancos de origem. A preparação antecipada dos dados reduziu o trabalho necessário no momento do consumo. A integração de diferentes fontes também ampliou as informações disponíveis para análise, permitindo novos cruzamentos e insights para o negócio.
