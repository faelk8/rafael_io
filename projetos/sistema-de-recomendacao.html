EXPERIÊNCIA PROFISSIONAL

Sistema de recomendação

Recomendação de produtos para clientes de uma empresa, com base em dados de compras e comportamento.

Sistema de recomendação Redis Estatística TF-IDF SQL

Problema e objetivo

Com o objetivo de aumentar a conversão de vendas, a empresa buscava uma solução para recomendar produtos aos clientes com base em suas compras anteriores e comportamento de navegação. A meta era criar um sistema que pudesse analisar os dados disponíveis e fornecer recomendações personalizadas em tempo real.

Arquitetura planejada

A análise considerava os seguintes dados:

  • Produtos mais comprados
  • Produtos mais visualizados
  • Grupos de produtos relacionados

A arquitetura do sistema de recomendação foi planejada para coletar e processar esses dados, utilizando algoritmos de filtragem colaborativa e baseada em conteúdo. O sistema foi projetado para identificar padrões de comportamento dos clientes e gerar recomendações relevantes.

Funcionamento

Todos os dias os produtos eram analisados e classificados de acordo com a frequência de compra e visualização. O sistema então gerava uma lista de recomendações personalizadas para cada cliente, que ficava disponível no Redis, quando um cliente acessava o site, as recomendações eram exibidas com base em seu histórico de compras e comportamento de navegação.

Para cada produto visualizado de acordo com o modelo escolhido, o sistema mostrava os produtos mais comprados e visualizados relacionados, aumentando a probabilidade de conversão.

Manutenção e automação

O sistema funcionava de forma autônoma, com atualizações diárias das recomendações. A manutenção envolvia a verificação periódica dos algoritmos e ajustes conforme necessário para melhorar a precisão das recomendações.

Resultados e aprendizados

O sistema de recomendação ajudou a aumentar a conversão de vendas, proporcionando uma experiência melhor para os clientes e aumentando a fidelidade da marca.
