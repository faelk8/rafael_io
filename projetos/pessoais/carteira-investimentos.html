PROJETO PESSOAL

Acompanhamento de carteira de investimentos

Sistema pessoal de análise de investimentos em ações e FIIs, com coleta de dados da B3 e web scraping, ELT em Python, PostgreSQL e dashboards em Power BI para acompanhar carteira, dividendos, preço médio, preço justo e oportunidades de aporte.

Python Pandas PostgreSQL Power BI Web Scraping B3 ELT Ações FIIs Método Bazin Análise fundamentalista Dividendos

Minha contribuição

Desenvolvi este sistema para acompanhar minha própria carteira e transformar dados dispersos de mercado, extratos e posições em uma visão única para análise. O projeto reúne coleta, tratamento, armazenamento, cálculos financeiros e visualização.

A arquitetura utiliza Python e Pandas no processo de ELT, PostgreSQL como base central e Power BI para análise visual. Os dados são atualizados mensalmente e combinam informações da B3, extratos e dados coletados por web scraping.

O problema que eu queria resolver

Acompanhar uma carteira apenas pela corretora mostra a posição atual, mas não necessariamente organiza todo o histórico necessário para responder perguntas que voltam todos os meses: quanto cada ativo representa, qual é o preço médio, como os dividendos evoluíram, qual foi a rentabilidade e quais ativos merecem uma análise antes de um novo aporte.

O projeto nasceu para centralizar essas informações e criar um processo repetível de revisão da carteira, com os mesmos critérios sendo aplicados ao longo do tempo.

Coleta e ELT dos dados

O fluxo começa com a coleta de dados de mercado, informações disponibilizadas pela B3, extratos e dados obtidos por web scraping. O processamento é feito em Python com Pandas.

Os dados são tratados e carregados no PostgreSQL, que funciona como base histórica para os cálculos e para os dashboards. Esse desenho separa a coleta da análise e permite manter a evolução da carteira ao longo do tempo.

Ações e fundos imobiliários

O sistema acompanha tanto ações quanto fundos imobiliários. Para cada posição, mantenho informações como quantidade, preço médio, cotação atual e desempenho percentual.

A análise também considera o comportamento dos últimos 12 meses e a evolução dos proventos, permitindo observar o ativo não apenas pelo preço atual, mas pela forma como ele vem se comportando ao longo do período.

Método Bazin e preço justo

Uma das referências utilizadas na análise é o método Bazin, principalmente pela relação entre preço, dividendos e retorno esperado. O sistema calcula métricas que ajudam a avaliar preço justo e preço teto antes de um novo aporte.

Utilizo como referência uma meta de retorno próxima de 1% ao mês. Esse valor não funciona como uma decisão automática de compra: ele é um critério para destacar ativos que merecem uma análise mais cuidadosa.

Análise fundamentalista

Antes de considerar um novo aporte, o sistema reúne indicadores fundamentalistas para apoiar a avaliação. A análise considera métricas como múltiplos, rentabilidade, endividamento, margens, payout e dividend yield.

A intenção não é substituir a análise do ativo por um único score, mas organizar as informações em um mesmo processo para facilitar comparação e investigação.

Dividendos como parte da estratégia

O acompanhamento de dividendos é feito mensal e anualmente. Essa visão permite observar não apenas valorização de preço, mas também a geração de renda ao longo do tempo.

Tenho preferência por analisar setores ligados a serviços essenciais e com histórico de distribuição de dividendos, como telecomunicações, saneamento, energia e bancos. O sistema ajuda a acompanhar essa exposição dentro da carteira.

Momento de entrada e saída

O acompanhamento de preço médio, cotação atual, retorno percentual e preço justo também serve para identificar momentos em que uma posição merece nova análise.

Isso ajuda tanto na avaliação de possíveis aportes quanto na revisão de posições já existentes. A ferramenta organiza os sinais; a decisão continua sendo feita após analisar o ativo e seu contexto.

Dashboards no Power BI

O Power BI transforma a base histórica em uma visão mais simples de acompanhar. Os dashboards reúnem evolução patrimonial, composição da carteira, preço médio, cotação, retorno por ativo e histórico de dividendos.

Durante a revisão mensal, essa camada visual permite sair de uma leitura isolada de cada ativo e enxergar melhor o conjunto da carteira.

Um projeto recorrente, não apenas uma aplicação pronta

Uma característica importante deste projeto é que ele continua sendo usado. Todos os meses os dados são atualizados, a carteira é revisada e os indicadores são novamente analisados.

Isso faz com que o sistema evolua junto com a necessidade real de uso. Mudanças no processo de análise ou novas informações relevantes podem ser incorporadas ao pipeline e aos dashboards.

Por que este projeto é importante para mim

Ele reúne Engenharia de Dados, análise com Python, modelagem em PostgreSQL, BI e um tema que estudo e acompanho continuamente. É também um exemplo de como gosto de trabalhar: transformar uma necessidade recorrente em um processo de dados estruturado e reutilizável.

Mais do que acompanhar números, o sistema cria uma disciplina de análise. Cada novo aporte passa por dados históricos, indicadores e critérios previamente definidos, reduzindo decisões baseadas apenas na percepção do momento.
